模块由两类资产组成：一是 `styles/*.yaml` 预置样式剧本（如 clean-professional、anime-ghibli、flat-motion-graphics、minimalist-diagram、premium-minimalist），每个文件通过 `identity/visual_language/typography/motion/audio/asset_generation/overlays/chart_palette/color_rules` 等顶层键声明一套完整的视觉与动效规范；二是 `playbook_loader.py` 作为唯一运行时入口，负责从 `STYLES_DIR` 及 `styles/custom/` 子目录查找同名 `.yaml` 文件并优先使用预设覆盖生成物。加载流程为 `load_playbook` → `yaml.safe_load` → `validate_playbook`（调用根级 `schemas/styles/playbook.schema.json` 做 JSON Schema 校验）。除 I/O 外，模块还内置纯 Python 实现的色彩数学工具（hex↔RGB↔HSL、sRGB 线性化、相对亮度）、三种色觉缺陷（deuteranopia/protanopia/tritanopia）混淆矩阵、WCAG 2.1 对比度计算、模块化字号比例（minor_second…golden）与字体搭配建议库，并通过 `validate_accessibility` 聚合 contrast / color_blind / font_size / typography 四类问题输出统一结果。依赖方向单向：YAML 是数据契约，Python 仅消费它，不反向修改样式文件。
