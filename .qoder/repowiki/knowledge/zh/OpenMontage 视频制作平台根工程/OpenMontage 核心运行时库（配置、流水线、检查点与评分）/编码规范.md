- 配置与清单数据统一通过 Pydantic `BaseModel` 或 `dataclass` 建模，并提供 `load()` / `from_dict()` / `to_dict()` 等序列化入口。
- 外部 YAML/JSON 清单在加载后必须立即用 `jsonschema.validate` 校验，错误统一包装为自定义异常（如 `CheckpointValidationError`、`ExtensionNotPermitted`）。
- 昂贵且不可变的资源（manifest、schema）通过 `@lru_cache(maxsize=...)` 缓存，并以 `_load_xxx_cached` 私有函数 + 公开只读 API 分离读写语义。
- 文件系统路径集中由 `lib.paths.REPO_ROOT` / `PROJECTS_DIR` 派生，禁止在各模块内硬编码相对路径。
- 可观测性写入（`events.emit_event`）采用 try/except 包裹全部 I/O，保证观测失败绝不影响主流程。
- 检查点写入采用先写 `.tmp` 再 `os.replace` 的原子替换模式，并在覆盖前将已完成/待审批的旧版本归档至 `history/`。
