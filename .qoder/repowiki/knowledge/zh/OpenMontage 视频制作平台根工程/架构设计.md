根工程作为编排层，不承载业务逻辑，而是把各子模块按职责解耦并统一入口：
- 依赖与环境：Makefile 提供 `setup`/`install`/`install-gpu`/`test`/`demo`/`hyperframes-doctor` 等顶层命令，自动创建 .venv（优先 uv）、安装 requirements.txt、在 remotion-composer 子目录执行 npm install、预热 HyperFrames npx 缓存，并生成 .env。
- 配置契约：config.yaml 集中声明 LLM provider、预算策略、检查点策略、输出编解码参数与各子模块路径（pipeline_dir/styles_dir/skills_dir/output_dir），被 lib_core、tools、styles、pipeline_defs 等子模块共同读取。
- 包发布：setup.py 以 setuptools 暴露 openmontage 包，python_requires>=3.10，固定 pyyaml/pydantic/jsonschema/python-dotenv/Pillow/requests/google-genai/openai 等跨子模块共享依赖。
- 运行期装配：tools 子模块的 BaseTool + ToolRegistry 自动发现机制是连接 pipeline_defs、lib_core、skills、styles、tests 的桥梁；schemas 子模块的 JSON Schema 被 styles、lib_core、tests/contracts 共同校验；remotion-composer 通过 npm 独立构建并由 Python 侧调用。
- 演示与验证：render_demo.py + render-demo.sh 作为零 API Key 的端到端入口，tests 通过 socket 拦截禁止真实网络访问以保证回归稳定。
