模块以扁平目录组织，每个子目录代表一个独立 skill（如 ffmpeg、threejs-fundamentals、remotion、elevenlabs、seedance-2.0 等），每个 skill 目录下包含一个 SKILL.md 作为该技能的入口与完整指南，部分 skill（如 ffmpeg）还附带 reference.md 作为补充参考。SKILL.md 采用 YAML front matter 声明 name、description、license、compatibility 等元数据，供上层 agent 框架加载和匹配触发条件；正文使用 Markdown 章节组织工作流、命令示例、最佳实践与错误排查。skill 之间相互独立、无代码依赖，仅通过统一的 SKILL.md 格式被外部 agent 发现与调用。
