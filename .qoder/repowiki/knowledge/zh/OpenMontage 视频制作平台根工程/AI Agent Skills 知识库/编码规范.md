- 每个 skill 目录以单一 SKILL.md 文件作为唯一入口，front matter 中必须包含 name 与 description 字段用于 agent 注册与触发。
- 文档结构统一采用「Quick Reference → 具体场景 → 常见问题/错误处理」的分节模式，便于快速检索命令与排错。
- 所有可执行命令均以带语言标记的 bash 代码块呈现，并在其后附注关键参数说明与适用场景。
- 涉及第三方 API 的 skill（如 setup-api-key）在 front matter 中声明 license 与 compatibility 约束，并在正文中以分步工作流引导用户完成配置。
- 跨 skill 协作通过引用上游产物路径（如 Remotion 渲染输出 out/video.mp4）约定输入输出契约，而非直接耦合代码。
