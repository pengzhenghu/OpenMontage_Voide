- 每个 schema 文件顶部声明 `$schema`、`$id`（采用 `openmontage/<domain>/<name>` 命名空间）、`title` 与可选 `description`，并显式设置 `type: object`。
- 通过 `required` 数组列出必填字段，并在 `properties` 中以 `const` 固定版本号（如 `version: "1.0"`）。
- 枚举型字段统一使用 `enum` 约束取值（如 `target_platform`、`status`、`operation`），避免自由文本歧义。
- 数值字段普遍搭配 `minimum`/`maximum` 限制合理范围（如分辨率、采样数、帧率、时长）。
- 在对象根级设置 `additionalProperties: false`，确保数据契约严格且拒绝未知字段。
- schema 按领域分目录组织（artifacts/checkpoints/pipelines/tools/styles），每个子目录含空 `__init__.py` 使其成为独立 Python 包。
