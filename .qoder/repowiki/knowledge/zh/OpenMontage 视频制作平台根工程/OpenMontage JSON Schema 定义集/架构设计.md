模块以纯数据声明形式组织，按领域子目录划分 schema 职责：`artifacts/` 描述创意产出物（brief、script、review、render_report 等），`checkpoints/` 定义可恢复的流水线快照结构，`pipelines/` 描述管线清单，`tools/` 约束外部工具（Blender、Three.js、Atlas 3D、Fal.ai、视频拼接）的输入参数，`styles/` 存放风格剧本规范。每个 `.schema.json` 文件自包含一个完整的 JSON Schema draft-2020-12 文档，通过 `$id` 使用 `openmontage/<domain>/<name>` 命名空间进行唯一标识，并通过 `additionalProperties: false` 严格禁止额外字段。Python 包仅保留空 `__init__.py`，表明该模块不暴露运行时逻辑，而是作为跨项目共享的契约被消费方直接读取和校验。
