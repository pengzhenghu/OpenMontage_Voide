- 所有公开 API 通过 IIFE 立即执行后挂载到 `window`（`InkTheater`、`InkPuppet`），内部工具函数保持私有，避免污染全局命名空间。
- 时间驱动全部基于 GSAP timeline 的 `onUpdate` 回调与进度参数，不使用 `setInterval`/`requestAnimationFrame` 等运行时时钟，确保 seek-safe 与确定性。
- 随机性一律通过 `rng(seed)` 生成的 Mulberry32 PRNG 派生，禁止调用 `Math.random`，使抖动、笔触噪声在相同 seed 下完全可复现。
- SVG 元素统一通过内联 `el(tag, attrs, kids)` 助手创建，属性名使用连字符（如 `stroke-width`），路径坐标经 `r2` 四舍五入到两位小数以保证输出稳定。
- 可组合部件采用工厂函数返回 `{ g, ...handles }` 结构（如 `parts.crank/gauge/hopper/lever/box`），调用方持有对可动画子节点的引用以便后续驱动。
- Clip 数据以 JSON 清单（`catalog.json`）+ 二进制帧数组（`clips/*.json`）分离描述元信息与关键帧，运行时通过名称查找，未知 clip 会 `console.warn` 并跳过。
