该模块为纯文档仓库，不包含可执行代码，按主题组织 Markdown 文件：`ARCHITECTURE.md` 描述 agent-first 编排、工具契约（BaseTool/ToolRegistry）、三层知识体系（Layer 1 工具 + Layer 2 skills + Layer 3 .agents/skills）、流水线 YAML 清单、检查点与预算治理；`PROVIDERS.md` 汇总所有云/本地提供商的 `.env` 变量、设置步骤、定价与模型覆盖表；`comfyui-adapter-plan.md` 是 ComfyUI 适配器的 RFC，定义 `tools/_comfyui/client.py`、`comfyui_image/video/music` 工具、工作流模板与选择器集成；`PR_REVIEW_GUIDE.md` 提供面向 PR 的审查框架，强调不引入 Python 编排逻辑、遵守 BaseTool 契约与工具发现机制；`apple-silicon-mps.md` 记录 MPS 设备自动检测路径与已知限制；`images/backlot/` 存放界面截图；`stage-gates/.gitkeep` 保留目录结构。各文档之间通过相互引用构成项目的单一事实来源。
