模块以 `src/index.tsx` 为 Remotion 入口，调用 `registerRoot(Root)` 注册根组件；`Root.tsx` 集中声明多个 Remotion Composition（Explainer、CinematicRenderer、TalkingHead、TitledVideo、HeroTitle、ProductReveal、CaptionOverlayOnly、CollageBurst、LyricOverlay、EndTag*），每个 Composition 绑定独立组件与默认 props。

核心编排层是 `Explainer.tsx`：定义 `Cut` / `Overlay` / `AudioConfig` 等数据接口，通过 `SceneRenderer` 对 `cut.type` 做分派（text_card、stat_card、callout、comparison、bar_chart、line_chart、pie_chart、kpi_grid、progress_bar、anime_scene、terminal_scene、screenshot_scene、图片/视频 fallback），并通过 `BackgroundImageLayer` / `BackgroundVideoLayer` 统一包裹背景图或背景视频；`OverlayRenderer` 负责 section_title、stat_reveal、hero_title、provider_chip 四类叠加层；顶层 `Explainer` 用 `Sequence` 按 in/out_seconds 排列各层，并挂载 CaptionOverlay 与 Audio（支持 music 淡入淡出与 loop）。

主题系统集中在 `Root.tsx`：`THEMES` 字典 + `resolveTheme()` 从 props.theme/playbook/themeConfig 解析出 `ThemeConfig`，被 Explainer 及所有子组件消费，保证颜色/字体/图表调色板一致。

可复用 UI 组件位于 `src/components/`，按职责拆分（TextCard、StatCard、CalloutBox、ComparisonCard、ProgressBar、HeroTitle、SectionTitle、StatReveal、ProviderChip、ParticleOverlay、AnimeScene、TerminalScene、ScreenshotScene），图表子目录 `components/charts/` 提供 BarChart/LineChart/PieChart/KPIGrid；类型与 fixtures 放在 `cinematic/` 下，资源解析由 `lib/resolveAsset.ts` 统一处理。

依赖方向单向：`index.tsx → Root → Explainer → components/*`，`Explainer` 不反向依赖具体组件实现，仅通过 type 字段分派，新增场景只需在 `SCENE_TYPES.md` 登记并在 `SceneRenderer` 加分支。
