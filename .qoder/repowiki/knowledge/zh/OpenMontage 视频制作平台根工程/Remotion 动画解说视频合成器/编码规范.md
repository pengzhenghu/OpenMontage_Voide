- 新增场景通过扩展 `Cut` 接口的 `type` 字面量并在 `SceneRenderer` 中增加 if 分支来注册，同时在 `SCENE_TYPES.md` 表格中登记该 type 的必填字段与用途。
- 所有视觉组件通过 `maybeWrapWithBg` 统一包裹 `BackgroundImageLayer` / `BackgroundVideoLayer`，使背景图/视频与前景内容解耦且共享暗色遮罩。
- 颜色与字体一律经由 `resolveTheme(props)` 返回的 `ThemeConfig` 注入，组件自身不硬编码主题色，仅在 cut 显式覆盖时回退到 theme 值。
- 动画使用 Remotion 的 `interpolate(frame, [from,to], [a,b])` 与 `spring(...)` 驱动，帧范围基于 `useCurrentFrame()` 和 `useVideoConfig().fps` 计算。
- Composition 在 `Root.tsx` 中以 `<Composition id=... component=... defaultProps=...>` 形式集中声明，durationInFrames 通过 `calculateMetadata` 或固定帧数推导。
- 可复用的 UI 组件统一导出至 `src/components/index.ts`，作为单一发布点供 `Explainer` 和其他 Composition 引用。
