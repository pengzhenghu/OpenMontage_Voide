- 每个技能文件遵循统一结构：When to Use → Prerequisites → Process（Step N）→ Self-Evaluate（评分量表）→ Common Pitfalls → Submit，便于 Agent 解析执行。
- 流水线导演技能以角色命名（executive-producer / research-director / script-director / scene-director / asset-director / edit-director / compose-director / publish-director），并在 `executive-producer.md` 中用 EP_STATE 对象维护跨阶段累积状态。
- 技能之间通过显式引用上游 artifact（如 `research_brief`、`proposal_packet`、`scene_plan`、`asset_manifest`）进行数据传递，而非隐式共享上下文。
- 质量门禁采用 PASS / REVISE / SEND_BACK 三态决策，REVISE 最多重试 3 次后 PASS WITH WARNINGS，防止无限循环。
- 新增工具或技能时不手动修改注册表，而是依赖 `tool_registry.discover()` 自动发现，仅通过 `agent_skills[]` 关联 Layer 3 技能。
- 创意类技能以“何时使用”作为触发入口，明确区分 selector tool（如 `image_selector`、`video_selector`）与 provider tool 的使用场景。
