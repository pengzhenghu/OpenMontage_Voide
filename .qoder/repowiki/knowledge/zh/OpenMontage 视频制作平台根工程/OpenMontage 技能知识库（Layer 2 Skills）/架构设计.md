本模块采用三层知识架构：Layer 1（`tools/tool_registry.py`）声明工具能力，Layer 2（本目录）提供 OpenMontage 专属约定，Layer 3（`.agents/skills/`）加载通用 API 知识。内部按职责划分为四个子目录——`core/` 存放 FFmpeg、Remotion、HyperFrames、WhisperX 等基础技术用法；`creative/` 涵盖剪辑、增强、提示词工程、图像/音乐/3D 生成等创意技巧；`pipelines/<pipeline>/` 以导演角色（executive-producer / research-director / script-director / scene-director / asset-director / edit-director / compose-director / publish-director）组织多套流水线（explainer、animation、cinematic、talking-head、screen-demo、clip-factory、podcast-repurpose、hybrid、avatar-spokesperson、localization-dub、character-animation），每套流水线由 `executive-producer.md` 作为状态机协调各阶段串行执行并维护 EP_STATE；`meta/` 提供跨流水线协议（onboarding、reviewer、checkpoint-protocol、skill-creator、taste-direction、bespoke-composition、capability-extension、checkpoint-protocol、video-reference-analyst、voice-performance-director、animation-runtime-selector）。所有技能通过 `INDEX.md` 统一索引，并以 Markdown 形式描述触发条件、前置依赖、分步流程、自评估量表与常见陷阱，供 Agent 在运行时按需加载。
