- 每个工具模块只定义一个继承自 BaseTool 的类，并在类级别声明 name、version、tier、capability、provider、runtime、stability、dependencies、input_schema、output_schema、resource_profile、retry_policy、fallback_tools 等元数据字段。
- 对外部重型依赖（如 requests、google.genai、google.auth）采用函数内懒导入，避免工具注册阶段的导入开销与硬依赖失败。
- API 客户端统一使用本地常量集中管理端点 URL、超时、错误码集合与环境变量名（如 ATLASCLOUD_API_KEY、GOOGLE_APPLICATION_CREDENTIALS），并通过专用异常类型（如 AtlasError）包装底层错误。
- 工具通过 dependencies 列表声明外部依赖，并使用 cmd:/binary:/env:/python: 前缀区分命令、二进制、环境变量与 Python 包三类检查。
- 选择器类（selector）将 provider 设为 'selector' 并声明一组 capabilities，由 ToolRegistry.find_by_capability 动态发现具体 provider，新增 provider 无需修改选择器代码。
- 耗时或付费操作通过 estimate_cost/estimate_runtime 返回预估值，并由 CostTracker.estimate → reserve → reconcile/refund 流程统一纳入预算治理。
