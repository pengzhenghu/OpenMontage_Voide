模块以 base_tool.py 中的 BaseTool 抽象为核心契约：所有子目录（video、audio、graphics、analysis、avatar、enhancement、capture、subtitle、character、publishers、_comfyui、_kling）下的具体实现均继承该基类，统一暴露 execute(inputs) -> ToolResult、get_info()、estimate_cost()、dry_run() 等接口，并通过 ToolTier/ToolStability/ToolRuntime/ExecutionMode/Determinism 等枚举声明元数据。

- 自动发现机制：tool_registry.py 的 ToolRegistry 通过 pkgutil.walk_packages 扫描 tools/ 下所有模块，用反射识别并实例化所有非抽象的 BaseTool 子类，跳过 base_tool 与 tool_registry 自身；提供按 tier/capability/provider/status/stability 查询、fallback 查找、provider_menu/capability_catalog/support_envelope 等报告能力。
- 执行插桩：BaseTool.__init_subclass__ 在子类定义时自动把 execute 包装为 _instrument_execute，向 lib.events 写入 start/error/finish 事件（可降级，无依赖时静默），并维护线程局部嵌套深度以支持 selector→provider 的委托调用。
- 依赖与环境：模块导入时即解析根级 .env 文件注入环境变量（_load_dotenv），check_dependencies 支持 cmd:/binary:/env:/python: 四类依赖声明。
- 横切服务：cost_tracker.py 提供预算估计/预留/结算/持久化的完整生命周期；google_credentials.py 封装 Google API Key 与服务账号双模式认证；atlas_client.py 提供 Atlas Cloud 三阶段（submit/poll/uploadMedia）通用 HTTP 客户端，被多个 image/video 工具复用。
- 选择器模式：如 video_selector.py、image_selector.py、tts_selector.py 等作为聚合层，根据运行时状态与评分从已注册的具体 provider 中路由到实际执行者，新增 provider 无需修改选择器。
