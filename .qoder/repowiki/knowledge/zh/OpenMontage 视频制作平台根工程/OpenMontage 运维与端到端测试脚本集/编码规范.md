- 每个脚本以 `from __future__ import annotations` 开头，并通过 `argparse.ArgumentParser` 暴露 CLI，入口统一为 `main()` 并在 `if __name__ == "__main__"` 中 `raise SystemExit(main())`。
- 通过 `REPO_ROOT = Path(__file__).resolve().parent.parent` 定位仓库根，再使用相对路径访问 `lib/`、`tools/`、`projects/`、`remotion-composer/` 等共享资源。
- 对可能产生副作用或调费的流程（Atlas 调用、Kling 付费 API、磁盘删除）提供显式开关（如 `--allow-paid`、`--live-*`、`--yes`），默认走 dry-run 或跳过。
- 对外部进程（playwright、remotion、ffmpeg、ffprobe、Backlot serve）一律通过 `subprocess.run` 调用，并设置超时与 `shell=(os.name == "nt")` 兼容 Windows。
- 结构化结果统一序列化为 JSON 写入 `artifacts/` 或 `internal/evals/captures/<timestamp>/report.json`，便于 CI 消费与回溯。
- Backlot 相关脚本复用 `lib.checkpoint.init_project` / `write_checkpoint` 与 `lib.events.emit_event` 来驱动真实的 pipeline checkpoint 协议，而非直接写文件系统。
