本模块为扁平的脚本集合，每个文件是一个独立可执行的 CLI（通过 `argparse` 暴露子命令），按职责分为四类：
- Backlot 演示与截图：`backlot_screenshot_stage.py` 在 `.backlot/screenshot-stage` 下用 `lib.checkpoint`/`lib.events` 构造虚构项目并通过 `OPENMONTAGE_PROJECTS_DIR` 启动 Backlot，再用 Playwright 抓取 README 截图；`backlot_visual_eval.py` 在此基础上对比 `internal/evals/goldens` 并支持 `--bless`；`backlot_simulate_run.py` 驱动真实 checkpoint 协议模拟流水线；`backlot_watch_captures.py` 轮询 `/api/project/{id}/state` 指纹变化后自动截图。
- 供应商 E2E smoke：`atlas_media_smoke.py` 通过 `tools.graphics.image_selector` / `tools.video.video_selector` 调用 Atlas Cloud（需 `--allow-paid`）；`kling_official_animated_explainer_e2e.py` 通过 `tools.tool_registry` 发现并编排 TTS/image/video/avatar/lip-sync，输出 `projects/<slug>/artifacts/kling_..._report.json`。
- Atelier 工程脚手架：`scaffold_atelier_project.py` 在 `projects/<slug>` 下生成 Remotion 工程骨架与 `art-direction.md`，强制手工创作；`atelier_snapshots.py` 借助 `VideoCompose()._stage_atelier_project` 调用 `npx remotion still` 为每场景生成缩略帧。
- 环境维护：`wan_disk_cleanup.sh` 基于 HuggingFace cache 模式匹配删除 Wan 模型权重、`.venv-wan` 虚拟环境与 `uv` 缓存，默认 dry-run，需 `--yes` 才删除。
依赖方向单向指向仓库根目录下的 `lib/`、`tools/`、`remotion-composer/`、`tests/contracts/`，脚本本身不引入业务逻辑，仅编排调用。
