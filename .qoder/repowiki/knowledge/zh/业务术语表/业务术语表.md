### Backlot
- 定义：OpenMontage 内置的本地可视化“看板”网页，实时展示制作进度：阶段点亮、脚本落地、素材卡片闪烁、每次供应商决策与花费都记录在板上。可通过 `python -m backlot open` 打开项目库或单个项目的实时看板，支持回放整条生产链。
- 别名：backlot、看板

### 流水线清单
- 定义：位于 `pipeline_defs/` 的 YAML 文件，定义一条完整的生产工作流（如 animated-explainer、cinematic、documentary-montage 等），包含阶段、工具、评审标准与成功门禁。Agent 读取清单后按 `research -> proposal -> script -> scene_plan -> assets -> edit -> compose` 顺序推进。
- 别名：pipeline manifest、YAML 清单

### 导演技能
- 定义：位于 `skills/pipelines/<流水线>/` 的 Markdown 指令文件，教 Agent 如何执行每个阶段。Agent 先读流水线清单知道“做什么”，再读导演技能知道“怎么做”，然后调用工具、自我评审、写检查点、在关键节点暂停等待人类审批。
- 别名：stage director skill、阶段技能

### 检查点
- 定义：每个阶段完成后写入的 JSON 状态快照，包含决策日志与成本快照，支持断点续做与审计追踪。被拒的“完成”状态不会通过门禁，所有被替代的检查点会被归档保留。
- 别名：checkpoint

### 评分选择器
- 定义：OpenMontage 在每个工具选择（视频/图片/TTS/音乐）上运行的 7 维评分引擎：任务匹配度(30%)、输出质量(20%)、控制特性(15%)、可靠性(15%)、成本效率(10%)、延迟(5%)、连续性(5%)。胜出者及其分数连同所有备选一起记录在决策审计轨迹中。
- 别名：scored selector、provider selection

### 交付承诺
- 定义：Agent 在提案阶段承诺的输出形态（如“motion-led”“数据驱动解释器”等），后续 compose 前会做 pre-compose validation，若实际计划违反交付承诺（例如声称 motion-led 却 80% 静态图）则阻止渲染。
- 别名：delivery promise

### 幻灯片风险评分
- 定义：对产出计划的 6 维度分析（重复性、装饰性视觉、弱运动、镜头意图、排版过度依赖、不支持的电影化宣称），防止输出变成“动画版 PowerPoint”。
- 别名：slideshow risk score

### Remotion / HyperFrames
- 定义：两种程序化视频合成引擎。Remotion 基于 React/Node.js，适合数据驱动的解释器与带动画的图片场景；HyperFrames 基于 HTML/CSS/GSAP，适合动效密集型作品（动态排版、产品宣传片、网站转视频、SVG 角色动画）。渲染运行时在提案阶段选定并锁定，不能静默切换。
- 别名：render_runtime、composition engine

### 风格手册
- 定义：位于 `styles/` 的 YAML 文件（clean-professional、flat-motion-graphics、minimalist-diagram 等），定义字体、色板、动效风格、音频配置与质量规则，Agent 在制作中按风格手册保持一致的视觉语言。
- 别名：style playbook、visual style

### 平台输出规格
- 定义：内置的针对不同发布平台的分辨率与画幅预设，如 YouTube Landscape (1920x1080)、YouTube Shorts (1080x1920)、Instagram Reels、TikTok、LinkedIn、Cinematic (2560x1080) 等。
- 别名：platform profile、output profile
